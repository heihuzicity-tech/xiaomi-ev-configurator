## 技术边界

- 已确认原站为 Next.js App Router + React、Tailwind/CSS Modules、GSAP、OverlayScrollbars、Swiper、Axios、Sentry 和 Xiaomi OneTrack。
- 三维层使用 Three.js r169 风格的定制运行时、GLTF/Draco/KTX2、WASM 解密和事件驱动渲染。
- 本阶段的“3D 已完成”只表示官方主包、解码器、配置表和运行脚本已本地化；真正的可旋转、换材质、开门 WebGL 运行时必须通过单独的集成验收，不能用静态帧冒充。
